Save for the boat

This preview saves a .zip. Open it, then copy the .hwr or .gpx file to the SD card.

Waypoint list
#NameLatitudeLongitudeRoute

Test a new file on one unit before a search: back up the unit's waypoints first, then import. Use a FAT32 card of 32 GB or less, kept separate from chart cards.

Humminbird routes hold 50 points, so larger grids are split into consecutive routes that join end to end. Waypoint names are cut to 11 characters and route names to 19.
